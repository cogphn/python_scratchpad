    Building a module

    With the spacetime CLI installed, scaffold and build a module:

    spacetime init --lang typescript --server-only my_module
cd my_module/spacetimedb && npm install
spacetime build        # → dist/bundle.js

    Rust modules (--lang rust) build to target/wasm32-unknown-unknown/release/*.wasm.

    Publishing here is equivalent to spacetime publish -s local <name> using this app's identity ({{ settings.identity|short_id(10) if settings.identity else 'none' }}).
